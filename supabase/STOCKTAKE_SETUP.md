# ตั้งค่าตรวจนับคลังและผู้ส่งใบเบิก

1. เปิด Supabase > SQL Editor ของโปรเจคสำเพ็ง
2. รันไฟล์ migrations/202610220001_stocktake_and_requisition_sender.sql ทั้งไฟล์ (ต้องมี items.stock_quantity จาก migration เดิม)
3. รีเฟรชเว็บ: คลัง > ตรวจนับคลัง / ประวัติ

กรอกชื่อผู้ตรวจนับ ยอดนับจริง และยืนยันปรับยอด เว้นว่างคือไม่ปรับ 0 คือหมด ยอดระบบหรือหน่วยที่เปลี่ยนระหว่างนับจะทำให้ทั้งรายการบันทึกถูกยกเลิกและต้องโหลดคลังใหม่ ไม่มีการปรับสำเร็จบางส่วน การส่งคำขอเดิมซ้ำไม่ปรับยอดซ้ำ

ระบบใช้ภายในโดยไม่ล็อกอินตามการตั้งค่าเดิม ผู้ที่เข้าถึงเว็บอ่านประวัติและยืนยันปรับยอดได้ ชื่อผู้ตรวจนับและผู้ส่งใบเบิกเป็นข้อมูลที่กรอก ไม่ใช่ตัวตนจากการเข้าสู่ระบบ
