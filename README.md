# ระบบเบิกสินค้า สำเพ็ง บุรีรัมย์

## แก้ปัญหารหัสแอดมินเข้าไม่ได้

หากหน้าล็อกอินแจ้ง “รหัสแผนกไม่ถูกต้อง” ทั้งที่ใช้รหัสแอดมินกลาง อาจมีฟังก์ชันล็อกอินรุ่นเก่าทับรุ่นใหม่ ให้ทำดังนี้:

1. เปิด Supabase โปรเจกต์ **ldrfcnzozlwiooxkwbvk** → **SQL Editor** → **New query**
2. เปิดไฟล์ [supabase/REPAIR_DEPARTMENT_AUTH.sql](supabase/REPAIR_DEPARTMENT_AUTH.sql) คัดลอกทั้งไฟล์ วางแล้วกด **Run**
3. เมื่อรันสำเร็จ กลับเว็บและลองเข้าด้วยรหัสเดิม หากยังไม่ผ่าน ให้ส่งข้อความผิดพลาดจาก SQL หรือหน้าเว็บเพื่อตรวจต่อ

ไฟล์นี้คืนฟังก์ชันล็อกอินแอดมิน/สต็อก การจดจำเข้าใช้งาน และการดูรหัสแผนก โดยไม่ตั้งรหัสใหม่หรือลบใบเบิก ใช้กับฐานข้อมูลที่ติดตั้งระบบรหัสแผนกแล้ว ไม่ใช่ไฟล์ติดตั้งฐานข้อมูลใหม่

**ไม่ต้องอัป Vercel เพื่อใช้ SQL ซ่อมนี้** เพราะเว็บเรียกฟังก์ชันจาก Supabase โดยตรง

## กรณีส่งใบเบิกบน Vercel ไม่ได้

SQL ซ่อมด้านบนแก้ระบบเข้าสู่ระบบ ไม่ได้ยืนยันว่าจะแก้ข้อผิดพลาดการส่งใบเบิกทุกกรณี หากยังส่งไม่ได้ ให้บันทึกข้อความที่แสดงหลังกดส่งและ URL ที่ใช้งาน ไม่ควรรันไฟล์ SQL เก่าซ้ำแบบสุ่ม เพราะอาจทับฟังก์ชันใหม่

ขั้นตอนติดตั้งและลำดับ migrations ทั้งหมด: [supabase/REQUISITION_SETUP.md](supabase/REQUISITION_SETUP.md)

## รันในเครื่อง

ติดตั้ง dependencies ด้วย npm install แล้วรัน npm run dev เปิด http://localhost:3000/xXMaINXx ตั้งค่า NEXT_PUBLIC_SUPABASE_URL และ NEXT_PUBLIC_SUPABASE_ANON_KEY ใน .env.local ให้ตรงกับโปรเจกต์
